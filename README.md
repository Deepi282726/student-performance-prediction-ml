# Student Performance Prediction Using Machine Learning

## Project Description
This project predicts whether a student will Pass or Fail using Machine Learning techniques.

## Features Used
- Study Hours
- Attendance
- Previous Score
- Assignment Score
- Sleep Hours

## Machine Learning Algorithms
- Decision Tree Classifier
- Random Forest Classifier

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## Model Evaluation
The models are evaluated using:
- Accuracy Score
- Confusion Matrix
- Classification Report
- ROC Curve
- AUC Score

## Dataset
The dataset contains student academic and study-related information used to predict the final result.

## Conclusion
The project demonstrates how supervised machine learning can be used to predict student performance based on academic and behavioral features.
